Russian Word of the Day
Где ближайшая станция метро?
Gdye BLIZH-ay-shuh-yuh stan-TSI-uh MET-ro?
Where is the nearest metro station?
Explanation +
This is one of the most practical phrases for getting around Russian cities, especially Moscow and St. Petersburg where the metro is the main transportation. Use it when you're lost and need to find the subway quickly. The word 'ближайшая' (nearest) is very useful for any location question. Example: 'Извините, где ближайшая станция метро?' (Excuse me, where is the nearest metro station?)
